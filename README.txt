Garden Doctor

Included files:
- index.html      (Your full Gardening App with manifest + Service Worker linked)
- manifest.json   (App name, theme color, and icon settings for Android)
- sw.js           (Offline Service Worker cache)
- icon-192.png    (App icon 192x192)
- icon-512.png    (App icon 512x512)

Steps to run on your phone & publish to Google Play:
1. Host this folder on any free HTTPS host (e.g., GitHub Pages, Netlify Drop, or Vercel).
2. Open the HTTPS link in Chrome on Android and tap "Install app" / "Add to Home screen" to test it like a native app.
3. Go to https://www.pwabuilder.com, paste your HTTPS URL, and download the Android (.aab) package.
4. Upload the .aab bundle + assetlinks.json to your Google Play Console developer account ($25 one-time fee).
